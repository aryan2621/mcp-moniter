# Cloud demos — user guide

Sample MCP servers that send tool-call metrics to the hosted product. Create a server and API key at [https://mcp-moniter.vercel.app/](https://mcp-moniter.vercel.app/), set `MCP_API_KEY`, run a demo, then watch that server’s metrics on the dashboard. Omit `METRICS_SERVER_URL` unless you are pointing at a local API.
